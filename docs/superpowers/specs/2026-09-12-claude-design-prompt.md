# Промт для Claude Design — редизайн интерфейса «Диктофона»

Направление «Студия» (графит + красный записи). Для другого направления замените
только блок «Палитра».

---

## Что за продукт

Личный командный центр ИИ-диктофона. Пользователь один — владелец. Носимый диктофон
(XIAO ESP32-S3) пишет разговоры и выгружает их на сервер частями. Сервер расшифровывает
части с разделением говорящих, затем собирает саммари: решения, факты, задачи, вопросы
без ответа, темы. Каждый пункт саммари привязан к реплике-основанию в записи — её можно
послушать одним нажатием. Интерфейс на русском языке.

При первом открытии за секунду должно быть ясно: это пульт управления записями. Что
записано сегодня, что сейчас обрабатывается, что ждёт моего решения.

## Референсы

- Apple: Voice Memos, «Настройки» iOS (grouped inset lists), тёмная тема macOS. Крупный
  заголовок, hairline-разделители, системные серые, один акцент, лёгкая полупрозрачность
  панелей.
- Plaud (AI note taker): запись — главный объект, волновая форма, спокойные карточки
  саммари, нейтральный фон без шума.
- Не референс: Officevibe, синие корпоративные дашборды, AI-градиенты, фиолетовый.

## Палитра

Только тёмная тема. Графит, не чёрный. Единственный хроматический акцент — красный
записи (Apple systemRed), и только там, где «запись / внимание / сейчас». Всё остальное —
серые и белый. Состояния источника — светофор маленькими точками.

| waveform | #8e8e93 | волна; активная часть — text-primary |

Типографика: один гротеск с оптическими размерами (SF Pro / Inter Display; Inter Tight
допустим). Заголовки страниц 40–48 px, weight 600, tracking −0.02em. Все числа
tabular. Моноширинный шрифт только для времени `00:12:34` и номеров сессий `0042`
(SF Mono / JetBrains Mono). Без серифов и курсива.

Формы: радиус 12 px у карточек, 8 px внутри, 999 у чипов. Карточки без теней — только
hairline или разница тона. Тень только у плавающего плеера, тонированная под графит.

## Экраны (артборды)

1. **Сводка** — главная, десктоп 1440. Командный центр:
   - Строка состояния устройства и конвейера: «Диктофон · последняя выгрузка 14 мин
     назад · 3 части» · «Расшифровка: 2 в очереди» · «Саммари: 1 ждёт». Красная
     пульсирующая точка «пишет», если выгрузка была меньше 5 минут назад.
   - Лента дня: горизонтальная шкала 07:00–22:00, записи — блоки с мини-волной,
     длительностью и числом задач; нажатие ведёт в сессию.
   - Четыре числа дня (минуты, разговоры, новые задачи, спорные места) — крупно,
     tabular, без рамок, разделены hairline.
   - «Мои открытые задачи» — grouped list: слева точка источника, справа срок;
     просроченный срок красный.
   - «Последние записи» — компактные строки.
2. **Сессия** — абзац саммари, темы чипами, секции «Решения / Факты / Задачи / Вопросы
   без ответа» как grouped lists с временем `00:12:34` и кнопкой «▶ основание».
   Говорящие: имя + переключатель «это я». Транскрипт: время, говорящий, текст.
   Плавающий плеер снизу: волна части, play, время, «часть 03 / 07».
3. **Записи** — список сессий: дата, длительность, волна-превью, статус (готово ·
   обрабатывается — жёлтая точка · ошибка — красная).
4. **Задачи** — фильтры «Открытые · Мои · Просроченные · Все» сегментированным
   контролом в духе Apple, список задач.
5. **Состояние** — очереди, последняя выгрузка, части с ошибкой, пропуски частей.
   Таблицы как grouped lists, тексты ошибок моноширинным.
6. **Сводка на телефоне** — 390 px. Те же блоки в один столбец, нижняя таб-панель
   вместо боковой: «Сводка · Записи · Задачи · Поиск · Ещё».

Навигация на десктопе: узкая боковая панель 220 px. Текущий раздел выделен серой
заливкой и белым текстом, не акцентом.

## Данные — живые, не плейсхолдеры

Имена: Марат, Айгерим, Данияр, Светлана. Проекты: «Posiflora», «Склад Алматы»,
«Смета по офису». Числа неровные: 1 ч 47 мин, 6 разговоров, 4 задачи, 2 спорных места.
Реплика: «Марат: давай смету по офису до пятницы, Данияру скину». Срок: «до пятницы ·
19 сен». Ошибка: «Deepgram 429: rate limit, попытка 3».

## Состояния

Показать отдельно: пустая сводка (сегодня записей нет, устройство молчит два дня);
загрузка — скелетон по форме карточек; ошибка загрузки inline с кнопкой «Повторить»;
задача, у которой источник не найден.

## Движение

Сдержанно. Цвет — 150–200 мс. Нажатие — scale 0.98. Списки появляются каскадом с шагом
30 мс. Живая красная точка — плавный пульс 2 с. Уважать prefers-reduced-motion.

## Чего не делать

Синий, фиолетовый, индиго. Градиенты. Три одинаковые карточки в ряд с иконкой сверху.
Тени на всём подряд. Ракета, щит, лампочка. Восклицательные знаки в текстах.
Title Case в заголовках. Иконки Lucide — взять набор в духе SF Symbols или Phosphor.

## Что отдать

Артборды 1–6 и отдельный артборд «Токены»: палитра, шкала текста, радиусы и компоненты
(карточка, строка списка, точка источника, чип, сегментированный контрол, плеер).
Реализация будет на Next.js и Tailwind v4 — имена токенов оставить как в таблице выше.
