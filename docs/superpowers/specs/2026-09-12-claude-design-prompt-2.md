## 3. Состояния интерактивных элементов

Один артборд «Состояния». Для каждого элемента ряд: default · hover · pressed ·
focus-visible · disabled (где есть) · selected (где есть).

- Строка grouped list (кликабельная): hover — фон `surface → surface-elevated`;
  pressed — `scale 0.98`; focus — кольцо `#f5f5f7` 2 px с отступом 2 px, внутри радиуса.
- Карточка записи с волной.
- Кнопки: primary (акцент, редкая), secondary (серый fill), ghost (только текст).
- Сегментированный контрол: ползунок под выбранным сегментом.
- Чип темы, кнопка «▶ основание», ссылка в тексте (подчёркивание только на hover).
- Поле ввода: default · focus · error (текст ошибки под полем, без красной рамки на всём).
- Точка источника: легенда трёх цветов с подписями «подтверждён · не подтверждён ·
  не найден».
- Пункт навигации: default · hover · текущий · с бейджем числа.
- Таб нижней панели: неактивный · активный.

## 4. Иконки

Набор — Phosphor, вес Regular, 1.5 px, размер 20 в навигации, 16 в строках. Показать
на артборде «Токены»: Сводка, Записи, Задачи, Вопросы, Проекты, Спорные, Поиск,
Состояние, Ещё; внутри страниц — play, pause, микрофон, галочка, предупреждение,
обновить, меню, закрыть, стрелка-шеврон, волна. Не Lucide. Без ракет, щитов и лампочек.

## 5. Движение

Отдельный артборд «Движение». Для каждой анимации — три кадра (начало · середина ·
конец) и строка спецификации: триггер, свойство, длительность, кривая. Где артборд
позволяет живой CSS — пусть анимация идёт вживую (пульс точки, shimmer скелетона,
бегущая волна).

Токены движения — добавить в «Токены»:

| Токен | Значение |
|---|---|
| duration-fast | 150 мс — цвет, hover |
| duration-base | 240 мс — появление, сдвиг |
| duration-slow | 420 мс — возврат после нажатия |
| ease-out | cubic-bezier(0.2, 0, 0, 1) |
| ease-spring | cubic-bezier(0.34, 1.3, 0.64, 1) — только сегментированный контрол |
| stagger | 30 мс между строками |

Анимации:

1. **Точка «пишет»** — пульс: `opacity 1 → 0.4 → 1`, `scale 1 → 1.15 → 1`, 2 с, бесконечно.
   Зелёная точка «на связи» не пульсирует.
2. **Появление списка** при загрузке страницы — каскад: каждая строка
   `opacity 0 → 1`, `translateY 8 px → 0`, duration-base, ease-out, шаг stagger.
   Не больше 12 строк каскадом, остальные сразу.
3. **Лента дня** — блоки записей появляются слева направо тем же каскадом; мини-волны
   отрисовываются как рост высоты столбиков 240 мс.
4. **Hover строки** — фон за duration-fast. **Нажатие** — `scale 0.98` за 150 мс,
   возврат за duration-slow.
5. **Сегментированный контрол** — ползунок скользит к выбранному сегменту 200 мс,
   ease-spring; текст меняет цвет за duration-fast.
6. **«▶ основание»** — страница плавно прокручивается к реплике, реплика получает
   подложку `surface-elevated`, которая гаснет за 1,2 с. Плеер одновременно
   переключает часть и начинает играть.
7. **Плеер** — появление снизу `translateY 100% → 0`, duration-base; play ↔ pause —
   смена иконки с кроссфейдом 120 мс; активная часть волны — заливка бежит слева
   направо в реальном времени.
8. **Смена статуса задачи** («Закрыть», «Снять») — текст строки меняет цвет на
   text-secondary, появляется чип состояния, строка остаётся на месте. Не удалять
   и не схлопывать: владелец должен видеть, что произошло.
9. **Скелетон** — shimmer: полоса света `hairline-strong` идёт слева направо 1,6 с.
10. **Ошибка запроса** — текст ошибки появляется под строкой `opacity + translateY 4 px`,
    duration-base. Без тряски.
11. **Лист «Ещё» на телефоне** — выезжает снизу 260 мс ease-out, фон затемняется до
    `rgba(0,0,0,0.5)`.
12. **Бейдж числа в навигации** — при изменении числа короткий `scale 1 → 1.2 → 1`,
    200 мс.

Чего не анимировать: числа дня (без count-up), заголовки страниц, переходы между
страницами, фон.

`prefers-reduced-motion: reduce` — все переходы сводятся к `opacity` 150 мс, пульс и
shimmer выключены, каскад отсутствует. В Tweaks добавить переключатель «Уменьшить
движение», который показывает этот режим.

## 6. Что отдать

- Артборды 7–15, «Состояния», «Движение», обновлённые «Токены».
- В «Токены» — блок кода: CSS custom properties палитры и движения, `@keyframes`

  в таблицах.
- Таблица передачи: компонент → состояния → используемые токены.
