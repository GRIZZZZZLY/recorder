# Память разговоров, этап 1 «Основа» — дизайн

Дата: 12 сентября 2026. Статус: утверждён в переписке, реализуется.

## Цель

Превратить веб-клиент из просмотрщика транскриптов в память разговоров: найти сказанное, дослушать основание каждого вывода, поправить говорящих, видеть состояние обработки. Речевая аналитика и контроль договорённостей идут следующими этапами и на этот дизайн опираются.

## Порядок этапов, согласованный с владельцем

1. Основа: поиск, переход из текста к аудио, редактирование говорящих, источник каждого вывода, состояние обработки. Этот документ.
2. Повседневная польза: единые задачи, вопросы без ответа, лента проектов, дайджест.
3. Речевая аналитика: определение своего голоса, темп, доля речи, частотные выражения с примерами.
4. Расширенная память: подготовка к встречам, история решений, поиск по смыслу.

Obsidian не подключаем. Общий «балл общения» не вводим. Перебивания не считаем по смене говорящих.

## Исправляемый дефект

Метка `time` в саммари была относительной внутри части. «00:04» в части 1 и в части 2 писались одинаково. Модель получает транскрипт с единой абсолютной шкалой сессии; смещение части равно сумме длительностей предыдущих частей, длительность берётся из размера файла в `parts.bytes`, потому что он есть у каждой части, включая нерасшифрованные.

## Данные

`transcripts.text` хранит чистый текст от Deepgram без меток. `transcripts.utterances` хранит JSON реплик: начало, конец, говорящий, текст — в секундах от начала части. Рендер с абсолютным временем и именами делается на лету.

`speaker_names(device_id, session, speaker, name, is_me)`: ручное имя для номера говорящего внутри сессии и флаг «это я». Флаг пока не участвует в расчётах; он накапливает размеченные образцы голоса для этапа 3. Исходный номер не теряется.

`transcript_fts`: виртуальная таблица FTS5, токенизатор `unicode61 remove_diacritics 2`. Строка на реплику: ключи части и реплики без индекса, текст и его лемматизированная копия. Индекс перестраивается при сохранении транскрипта части.

Данных на сервере нет, миграции не нужны.

## Поиск

Запрос лемматизируется `pymorphy3`, ищется по колонке лемм с префиксным совпадением последнего слова. Ответ — реплики с подсветкой, именем говорящего, абсолютным временем и кнопкой «слушать». Известное ограничение: видовые пары вроде «обсудить / обсуждать» лемматизация не сводит; это задача поиска по смыслу в этапе 4. Без `pymorphy3` система работает на простых токенах в нижнем регистре.

## Источник вывода

У каждого решения, факта, задачи и вопроса без ответа два обязательных поля: `time` в формате `Ч:ММ:СС` по абсолютной шкале и `quote` — дословный фрагмент из транскрипта. После ответа модели сервер сверяет цитату с репликами вблизи указанного времени. Нашлась — у пункта кнопка «Послушать основание» на конкретную реплику. Не нашлась — пункт помечен «источник не подтверждён», но перемотка по времени всё равно доступна. Эта пометка становится первым видом спорных мест этапа 2.

В схему добавлен список `open_questions`: вопросы, которые прозвучали, но явного ответа или решения в записи не найдено.

## Переход текст → аудио

Транскрипт рендерится по репликам с атрибутами части и локальной секунды. Один плеер на часть. Клик по реплике переключает нужный плеер, перематывает и запускает. Инлайн-скрипт без зависимостей.

## Говорящие

На странице сессии у каждого номера поле имени и переключатель «это я». Сохраняется формой POST за сессию, подставляется в транскрипт, поиск и саммари. Исходный текст не меняется.

## Состояние обработки

Страница `/status`: длина очереди расшифровки и саммари; части с ошибками и текстом ошибки; сессии с пропуском номеров частей; восстановленные части; расхождение длительности по размеру файла и по ответу Deepgram больше 2%; время последней выгрузки по устройствам; минуты Deepgram по готовым расшифровкам как оценка расхода кредита.

## Проверки

Абсолютная шкала при двух и трёх частях. Цитата найдена и цитата не найдена. Поиск находит слово по другой форме. Переименование не трогает исходные данные. Страница состояния видит пропуск части и расхождение длительности. Клик-перемотка — атрибуты в разметке.

## Стоимость

Поиск, перемотка, говорящие и состояние не требуют ИИ. Источник вывода и вопросы без ответа входят в существующий запрос саммари и удлиняют его; лимиты подписки расходуются. Deepgram не затрагивается.
